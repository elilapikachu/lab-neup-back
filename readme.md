# Bienvenido al back de neup

---

Aqui podras encontrar la información de instalación de los componentes 
debes tener graddle y java. En este proyecto utilizamos estas herramientas.

* Java 21 
* Graddle Gradle 9.0.0 (Recuerda refrescar el graddle cuando descargues el proyecto)

---

Para iniciarlizar la ejecución del back ejecuta el comando.

`./gradlew bootRun
`

tambien puedes ejecutar el aplicativo atravez de NeupApplication.

---

## Nota

recuerda ejecutar primero el back antes que el front para que se puedan integrar de manera correcta
